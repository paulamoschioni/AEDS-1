# AEDS 1
Algoritmos e estruturas de dados 1 | Completo no primeiro período de 2026

Repositório com os códigos desenvolvidos durante a disciplina de AEDS 1 
no curso de Ciência da Computação (PUC Minas), no primeiro semestre de 2026.

## 📂 Estrutura

- **`listas/`** — Exercícios das listas oficiais propostas em aula, organizados 
  por número (lista01, lista02, ...). Cada lista tem uma matéria-foco. 
- **`livros/`** — Exercícios resolvidos de livros-texto de apoio , 
  separados por autor/obra
- **`extras/`** — Desafios extras, códigos exploratórios e pequenos projetos 
  pessoais feitos por curiosidade ou prática adicional

## 🛠️ Temas abordados

- Estruturas condicionais (lista 01)
- Estruturas de repetição (lista 02)
- Modularização (lista 03)
- Recursividade (lista 04)
- Ponteiros (lista 05)
- Arquivos (lista 06)
- Vetores e matrizes (lista 07)
- Manipulação de caracteres
- Structs (lista 08)
- Classes (lista 09)


## 🛠️ Tecnologias

- Linguagem: C / C++ 
- Ambiente: CodeBlocks
